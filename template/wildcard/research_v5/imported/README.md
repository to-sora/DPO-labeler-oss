# V5 Imported Trial Wildcards

This directory contains V5-owned copied and curated wildcard files for the
single imported-source trial workflow.

- Downloaded source packs remain untouched.
- These files are copied from either existing `research_v5` wildcards or
  downloaded wildcard packs under `wildcard/`.
- The trial uses these imported files only through
  `prompt_templates/research_v5/trial_hybrid_compact_*_adult.txt`.

The goal is to test broader variety without directly depending on the large raw
downloaded packs at runtime.
