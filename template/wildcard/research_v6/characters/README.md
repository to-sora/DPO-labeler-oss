# V6 Character Packs

These files are a neutral extended identity layer now wired into V6.

- One game per txt file.
- One character-like prompt identity per line.
- Line format is `character or notable alias/variant (game), game`.
- Packs prioritize broad prompt coverage, so major aliases, in-game handles,
  prominent alternate versions, and notable female NPCs may appear alongside
  base identities when a game's famous female roster is smaller than the
  requested coverage target.
- These packs are used by V6 templates as an additional character source.
- Later they can be split into family-specific packs for `illustration`,
  `sdxl_anime_base`, and `pony`.

The `ggo.txt` pack covers Gun Gale Online-related titles, including
`Sword Art Online Alternative Gun Gale Online` and `Sword Art Online: Fatal Bullet`.
